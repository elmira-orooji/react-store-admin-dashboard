# مشخصات کامپوننت‌های پایه

این سند مشخصات اولیه Button، Input، Select، Badge و Card را برای طراحی و پیاده‌سازی یکدست تعریف می‌کند.

## قواعد مشترک

- ارتفاع کنترل اصلی ۴۴ پیکسل است.
- focus با حلقه ۲ پیکسلی رنگ Primary و فاصله ۲ پیکسل نمایش داده می‌شود.
- گوشه کنترل‌ها ۸ پیکسل است.
- انیمیشن تغییر رنگ و border برابر ۱۲۰ میلی‌ثانیه است.
- کنترل disabled باید از نظر ظاهری و برنامه‌ای غیرفعال باشد.
- متن هیچ کنترل اصلی از ۱۴ پیکسل کوچک‌تر نمی‌شود.
- آیکن کنترل‌ها ۱۸ یا ۲۰ پیکسل است و در رابط RTL در جای درست قرار می‌گیرد.

## Button

### اندازه‌ها

| اندازه | ارتفاع | padding افقی | کاربرد |
|---|---:|---:|---|
| Small | ۳۶px | ۱۲px | جدول و بخش فشرده |
| Medium | ۴۴px | ۱۶px | اندازه پیش‌فرض |
| Large | ۵۲px | ۲۰px | صفحه ورود یا اقدام اصلی برجسته |

### گونه‌ها

#### Primary

برای مهم‌ترین اقدام هر بخش مانند «ذخیره محصول» استفاده می‌شود.

- پس‌زمینه Primary 600
- متن سفید
- hover با Primary 700
- disabled با opacity کمتر و بدون واکنش hover

#### Secondary

برای اقدام مهم با تأکید کمتر مانند «انصراف» یا «مشاهده پیش‌نمایش».

- سطح سفید
- متن اصلی
- border خنثی

#### Ghost

برای اقدام کم‌اهمیت مانند «پاک‌کردن فیلترها».

- پس‌زمینه شفاف
- متن Primary
- hover با پس‌زمینه Primary Subtle

#### Destructive

برای حذف یا خروج بدون ذخیره.

- متن Danger
- پس‌زمینه Danger Subtle
- متن اقدام باید روشن باشد؛ فقط «تأیید» کافی نیست.

### حالت Loading

- عرض دکمه تغییر نمی‌کند.
- متن به شکل مشخصی مانند «در حال ذخیره…» تغییر می‌کند.
- spinner در کنار متن دیده می‌شود.
- دکمه تا پایان عملیات disabled است.

### Button آیکن‌تنها

- حداقل ۴۰ در ۴۰ پیکسل
- tooltip برای توضیح کوتاه
- نام دسترس‌پذیر الزامی
- برای عملیات حساس مناسب نیست

## Input

### ساختار

1. Label
2. Input
3. متن راهنما یا خطا

Label همیشه نمایش داده می‌شود. placeholder فقط نمونه مقدار است.

### ابعاد

- ارتفاع: ۴۴px
- padding افقی: ۱۲px
- border: یک پیکسل
- radius: ۸px
- فاصله label تا input: ۸px
- فاصله input تا helper: ۶px

### حالت‌ها

- Default: border خنثی
- Hover: border تیره‌تر
- Focus: border Primary و focus ring
- Filled: مانند Default با مقدار قابل خواندن
- Error: border و متن خطای Danger
- Disabled: سطح خنثی و متن کم‌رنگ‌تر
- Read-only: ظاهر عادی با پس‌زمینه خنثی؛ با disabled اشتباه نمی‌شود

پیام خطا باید روش اصلاح را مشخص کند. «ورودی نامعتبر است» به‌تنهایی کافی نیست.

## Select

Select از قواعد Input پیروی می‌کند.

- فلش بازشدن با جهت RTL هماهنگ است.
- گزینه اولیه «انتخاب کنید» مقدار معتبر محسوب نمی‌شود.
- در حالت چندانتخابی یا فهرست قابل جست‌وجو، از کامپوننت جداگانه Combobox استفاده می‌شود.
- تغییر گزینه بدون اقدام حساس بلافاصله اعمال می‌شود.
- برای تغییر وضعیت سفارش، انتخاب با دکمه ثبت و دیالوگ تأیید همراه است.

## Badge

Badge برای نمایش وضعیت یا دسته‌بندی است و تعاملی نیست.

### ابعاد

- ارتفاع تقریبی: ۲۸px
- padding افقی: ۱۰px
- فاصله نقطه یا آیکن تا متن: ۶px
- radius: کاملاً گرد
- اندازه متن: ۱۲px با وزن ۵۰۰

### گونه‌ها

- Neutral: وضعیت عمومی یا غیرفعال
- Info: ارسال‌شده یا اطلاعاتی
- Success: تحویل‌شده یا فعال
- Warning: در انتظار بررسی یا کم‌موجود
- Danger: لغوشده، خطا یا ناموجود

Badge نباید به‌جای Button یا فیلتر قابل حذف استفاده شود. فیلتر فعال یک Chip تعاملی جداگانه است.

## Card

### ساختار پایه

- Header اختیاری
- Content
- Footer یا actions اختیاری

### مشخصات

- سطح سفید در تم روشن
- border یک پیکسل
- radius برابر ۱۲px
- padding پیش‌فرض ۲۴px
- padding فشرده ۱۶px
- بدون سایه در حالت عادی

### گونه‌ها

#### Content Card

برای گروه اطلاعات مستقل مانند «خلاصه پرداخت».

#### Metric Card

شامل label، مقدار و توضیح کوتاه. تمام سطح فقط زمانی قابل کلیک است که مقصد مشخصی داشته باشد.

#### Interactive Card

اگر قابل کلیک باشد:

- نشانگر hover دارد.
- focus روی کل کارت دیده می‌شود.
- داخل آن کنترل تعاملی تو در تو قرار نمی‌گیرد.
- عنوان مقصد در نام دسترس‌پذیر مشخص است.

### موارد منع استفاده

- هر ردیف جدول نباید Card شود.
- Card داخل Card قرار نمی‌گیرد.
- برای جداکردن هر پاراگراف از Card استفاده نمی‌شود.

## چیدمان موبایل

- Button اصلی می‌تواند تمام عرض شود، اما این رفتار پیش‌فرض نیست.
- فیلدها و Selectها تمام عرض‌اند.
- Card با padding شانزده پیکسل نمایش داده می‌شود.
- گروه دکمه‌ها در صورت کمبود فضا عمودی می‌شوند؛ Primary بالاتر قرار می‌گیرد.
- Badge نباید متن را به چند خط بشکند.

## دسترس‌پذیری

- کنتراست متن و پس‌زمینه حداقل AA را هدف می‌گیرد.
- حالت hover تنها راه تشخیص تعامل نیست.
- focus حذف یا مخفی نمی‌شود.
- خطا با `aria-describedby` به فیلد متصل می‌شود.
- loading با متن یا `aria-live` اعلام می‌شود.
- Badge متنی است و معنی آن فقط به رنگ وابسته نیست.

## معیار پذیرش

- تمام کامپوننت‌ها در تم روشن و تاریک خوانا هستند.
- Button در حالت loading تغییر عرض محسوس ندارد.
- Input و Select حالت error، disabled و focus دارند.
- Badge فقط نمایشی است و با کنترل تعاملی اشتباه نمی‌شود.
- Card در عرض ۳۲۰ پیکسل از صفحه بیرون نمی‌زند.
- مقادیر طراحی با فایل `design/components.json` هماهنگ‌اند.
