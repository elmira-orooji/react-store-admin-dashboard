# Store Admin Dashboard

پروژه تمرینی طراحی و پیاده‌سازی یک داشبورد مدیریت فروشگاه با React است.

## وضعیت پروژه

- فاز ۱: تعریف نیازمندی‌های محصول و UX — انجام شد
- فاز ۲: معماری اطلاعات و جریان‌های کاربر — انجام شد
- فاز ۳: وایرفریم صفحات اصلی — انجام شد
- فاز ۴: طراحی UI و Design System — در حال انجام
- فاز ۵: پیاده‌سازی React

جزئیات فاز اول در [سند نیازمندی‌های محصول](docs/product-requirements-fa.md) قرار دارد.

معماری اطلاعات و جریان‌های اصلی در [سند معماری اطلاعات](docs/information-architecture-fa.md) قرار دارد.
