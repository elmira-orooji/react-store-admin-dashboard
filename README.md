# Vitrino Storefront

طراحی و پیاده‌سازی یک فروشگاه اینترنتی فارسی با React. تمرکز پروژه روی تجربه خرید سریع، نمایش درست اطلاعات محصول و رابط واکنش‌گراست.

## مسیر فعلی پروژه

- تعریف MVP فروشگاه و نیازمندی‌های UX — انجام شد
- معماری اطلاعات و جریان خرید — انجام شد
- بازطراحی هویت بصری فروشگاه — انجام شد
- طراحی UI صفحه خانه و موبایل — انجام شد
- راه‌اندازی React و پیاده‌سازی App Shell — انجام شد
- پیاده‌سازی Hero، دسته‌بندی‌ها و پیشنهادهای ویژه صفحه خانه — انجام شد
- پیاده‌سازی فهرست محصولات، مرتب‌سازی و فیلترها — انجام شد

نیازمندی‌های نسخه فروشگاهی در [سند محصول Storefront](docs/storefront/product-requirements-fa.md) قرار دارد.

ساختار صفحات و جریان خرید در [معماری اطلاعات Storefront](docs/storefront/information-architecture-fa.md) تعریف شده است.

مشخصات طراحی نهایی خانه در [UI صفحه خانه](docs/storefront/home-ui-fa.md) قرار دارد.

## محدوده MVP

- صفحه خانه
- دسته‌بندی و فهرست محصولات
- جست‌وجو و فیلتر
- جزئیات محصول
- سبد خرید
- ورود و ثبت‌نام ساده
- انتخاب آدرس و ثبت سفارش آزمایشی

## اجرای محلی

برای اجرای پروژه و تست‌ها از Node.js نسخه ۲۴ استفاده کنید.

```bash
npm install
npm run dev
```

بررسی کیفیت:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

فهرست محصولات در مسیر `/#products` قرار دارد. جست‌وجو و دسته انتخاب‌شده در آدرس صفحه نگه داشته می‌شوند؛ فیلترهای دیگر تا زمانی که روی همان صفحه هستید فعال می‌مانند.

در این مرحله ۱۲ محصول نمونه داریم. جزئیات محصول و سبد خرید کامل هنوز پیاده‌سازی نشده‌اند؛ دکمه افزودن فقط شمارنده سبد را تغییر می‌دهد.

## مسیر طراحی

طراحی از الگوهای رایج فروشگاه‌های بزرگ ایرانی الهام می‌گیرد: جست‌وجوی برجسته، دسته‌بندی قابل دسترس، کارت محصول متراکم و ناوبری ساده موبایل. هویت بصری، متن‌ها، تصاویر و کامپوننت‌ها مستقل طراحی می‌شوند.
